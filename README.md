# C Systems Programming

A collection of projects completed during my Systems Programming course (CSCE 3600) at the University of North Texas.

These projects cover C programming, Linux, shell scripting, networking, multithreading, memory management, and data processing.

## Projects

| Project | Description |
|---|---|
| [ASCII Bits & Bytes](./ascii_bits.c) | Converts ASCII characters into decimal, hexadecimal, and binary representations. |
| [XOR Integer Swap](./xor_swap.c) | Swaps integers using bitwise XOR and dynamic memory allocation. |
| [Regex Text Processing](./regex-text-processing) | Extracts structured information using regular expressions. |
| [UDP Network Monitoring](./udp-network-monitoring) | Simulates packet loss and measures network latency using UDP sockets. |
| [Linux Task Automation](./bash-task-automation) | Automates file organization, reminders, system monitoring, and activity logging. |
| [Multithreading Optimization](./multithreading-optimization) | Uses mutex locks and condition variables to reduce busy waiting. |
| [Linux Data Processing](./linux-data-processing) | Processes and transforms structured data using sed and GAWK. |
| [TCP Client-Server Communication](./tcp-client-server) | Establishes TCP connections and transfers messages between a client and server. |
| [Interprocess Communication](./process-communication) | Implements command pipelines and input/output redirection using Linux system calls. |
