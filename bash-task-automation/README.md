# Linux Task Automation & Personal Assistant

A Bash script developed for my Systems Programming course at UNT to automate everyday tasks in a Linux environment.

## Features

- Displays the date, calendar, and running process count.
- Organizes files and moves log files into a separate folder.
- Allows users to add, view, and delete reminders.
- Categorizes entered heart rate values.
- Records user activities in a log file.
- Supports signal handling and debug mode.

## Technologies

Bash, Linux, Shell Scripting, Git

## How to Run

`bash personal_assistant.sh`

For debug mode:

`bash personal_assistant.sh --debug`

## What I Learned

This project helped me practice shell scripting, functions, arrays, file management, task automation, and signal handling.
