# Linux Data Processing & Automation

A collection of sed and GAWK scripts developed during my Systems Programming course at UNT to practice text processing, data filtering, and automated reporting.

## Features

- Text editing and pattern matching.
- Phone number formatting and character substitution.
- Linux process analysis and filtering.
- Student grade calculation and missing data handling.
- Mathematical calculations and angle normalization.

## Technologies

Linux, Bash, sed, GAWK, Regular Expressions

## What I Learned

These exercises helped me understand how to extract, clean, transform, and process structured data using Linux command-line tools.
