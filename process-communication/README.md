# Interprocess Communication & Pipes

Two C programs completed during my Systems Programming course at UNT to practice Linux system calls, file redirection, and process communication.

## Features

- Standard input and output redirection.
- Command execution using execvp().
- Process creation using fork().
- Communication between processes using pipes.
- File descriptor management using dup2() and close().

## Files

- `redirection.c` – Redirects input and output when executing grep.
- `pipeline.c` – Connects cat, grep, and cut commands using pipes.

## Technologies

C, Linux, GCC, Unix System Calls

## What I Learned

This project helped me understand how Linux processes communicate, execute commands, and manage input and output.
